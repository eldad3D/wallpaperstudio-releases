# Wallpaper Studio - releases

Built program files for Wallpaper Studio's in-app updates. No source code, no user data.

**First install:** download [WallpaperStudio-win64.zip](https://github.com/eldad3D/wallpaperstudio-releases/raw/main/download/WallpaperStudio-win64.zip),
unzip it anywhere and run `WallpaperStudio.exe` (Windows may say "Windows protected your PC": More info > Run anyway).

**Updates:** the app looks here a few seconds after it starts and shows *Update to x.y* when there is a newer
version. Only the files that changed are downloaded. Your sets live in `%APPDATA%` and are never touched.
